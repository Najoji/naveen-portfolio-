# Naveen Joseph Jino — Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload the folder to a new GitHub repository.
3. In Vercel, choose **Add New → Project** and import that repository.
4. Framework preset: **Other**.
5. Leave Build Command and Output Directory blank (or use `.` as the output directory if Vercel requests one).
6. Click **Deploy**.

## Before publishing
- Check your email address and phone number in `index.html`.
- Add a professional photo if you want one; the current hero artwork is CSS-generated.
- Verify project descriptions and awards are accurate.
- The site uses Google Fonts over the internet; system font fallbacks are included.
